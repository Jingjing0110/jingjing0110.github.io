Updating GitHub
  Copy the edited Jekyll source files into your existing repository, retaining
  their paths. Include the shared _includes/ and _layouts/ files, new CSS/JS,
  source pages, _portfolio/ figure metadata, images/, files/, and the existing
  research-figure Sass import. Review the diff, commit, and push as usual.
  No website has been published or pushed during this update.
  The existing GitHub Pages workflow and main navigation paths are retained.
